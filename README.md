Atividade 02 - Desenvolvimento Backend.

Evolução da API REST desenvolvida na Atividade 01, com implementação de novos recursos e aprimoramento da arquitetura.

### Tecnologias
Java, Spring Boot, Spring Data JPA, Bean Validation, SpringDoc OpenAPI, Maven.

### Como executar
./mvnw spring-boot:run

Acesso: http://localhost:8080
Swagger: http://localhost:8080/swagger-ui.html
